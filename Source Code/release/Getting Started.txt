SINO 0.10 / AKN Fork Development Preview

1. Start SINO

On Windows, place SINO.iso, Start SINO.cmd and launch.ps1 in the same folder,
then double-click Start SINO.cmd. Install QEMU for Windows or set
SINO_QEMU_DIR to its directory. The launcher also searches PATH and
Program Files\qemu.

The VM uses 4096 MiB RAM and one virtual CPU. It boots from the read-only
ISO and creates a 16 MiB Data/data.img for personal files on first launch.
Close the VM before replacing the ISO or backing up the disk.

2. Use the Shell

SINO opens an 80 by 25 text console. Type help for commands. The US keyboard
layout supplies ASCII input. Use arrow keys to edit or recall commands, Tab
to complete names, and Shift+PageUp or Shift+PageDown to browse output.
Ctrl+C cancels the foreground command. Ctrl+D ends input.

The Shell workspace maps to /home/user. Successful file changes are saved
before the next prompt. If saving fails, use sync to retry. /boot is read-only
and /tmp is temporary. File contents and UTF-8 filenames are preserved.

3. Build from source

Install Node.js, Python and GCC/GNU Binutils with i386 output. NASM 3.02 is
included in Source Code. Set SINO_TOOLCHAIN to the GCC bin directory if
needed. From the repository root, run:

  powershell -NoProfile -ExecutionPolicy Bypass -File dev.ps1 -BuildOnly

The script prints the ISO's directory under Build Output/dev/runs.
Copy that ISO alongside the two launcher files to run the release.
See Source Code/docs/testing.md for targeted validation commands.
