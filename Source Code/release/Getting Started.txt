SINO 0.10 / AKN Fork Development Preview

1. Start SINO

On Windows, place SINO.iso, Start SINO.cmd and launch.ps1 in the same folder,
then double-click Start SINO.cmd. Extract any ZIP completely before starting.
Install QEMU for Windows separately, or set SINO_QEMU_DIR to its directory.
The launcher also searches Program Files\qemu and PATH.
Official download: https://www.qemu.org/download/#windows

Every session boots from the read-only ISO. On first launch, the launcher
creates a 16 MiB Data/data.img for personal files. Keep this file between
sessions and run sync in the Shell before closing the VM to save changes.
Close the VM before replacing the ISO or backing up the data disk.
Repeated launches restore the existing window. Ctrl+Alt+G releases the mouse.

2. Desktop and Shell

F1 opens File Manager; F2 opens the writable SI-SHELL; F3 opens the built-in
text editor; F4 opens Calculator; F6 opens Clock; F7 opens system settings.
F12 opens a read-only Shell session. Ctrl+Space switches English/Pinyin input.
Ctrl+S saves a document and Ctrl+W closes a window. Alt+Tab switches windows.

Native .snx programs run directly. .app entries and .lnk shortcuts provide
application launch routes. The writable Shell supports run, file operations,
pipes and sync. Type help for commands. /boot is read-only, /tmp is temporary,
and /home/user is saved to the data disk when committed with sync.

3. Build from source

Requirements: Windows, Node.js, Python and GCC/GNU Binutils capable of i386
output. NASM 3.02 and routine font resources are included in Source Code.
Set SINO_TOOLCHAIN to your GCC bin directory if it is not already on PATH.

From the repository root:
  powershell -NoProfile -ExecutionPolicy Bypass -File dev.ps1 -BuildOnly

The command prints the new ISO's directory under Build Output/dev/runs.
To assemble a runnable folder, copy that ISO and the two launch files into it.
Use the root Start development command (启动开发版.cmd) for local development.
From Source Code, build-release.ps1 -OutputDirectory PATH writes an ISO to PATH.
See Source Code/docs/testing.md for focused validation commands.

4. Status and licenses

This is a 32-bit x86 BIOS operating-system prototype, validated in QEMU.
Read Release Notes.md for capabilities and limitations. Project code is MIT;
fonts, input data and NASM retain their own licenses. Keep Documentation/Licenses
and Source Code/SOURCES.md when redistributing. QEMU is not bundled.
