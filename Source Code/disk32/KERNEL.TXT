SINO32 KERNEL / SINO 0.10

The BIOS loads a 2.88 MB FAT12 image at physical address 2 MiB. The kernel
mounts it read-only at /boot. The default QEMU profile is 4096 MiB and one CPU.

The non-PAE kernel manages usable E820 memory below 4 GiB. Direct mappings
cover the low 1 GiB; the kernel maps high pages temporarily. Native SNX
programs run in Ring 3 with private page tables and guarded thread stacks.
The system supports 64 processes, four threads per process and 24 handles per
process. A user-mode fault terminates the affected process.

The VFS has 128 nodes and a 64 KiB per-file limit. Personal files use two
CRC-checked snapshot banks on a separate ATA disk. The network stack supports
loopback IPv4, ICMP, UDP and TCP.
