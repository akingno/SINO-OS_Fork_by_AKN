SINO 0.10 / AKN Fork

SINO is a 32-bit x86 BIOS operating system. It boots to an 80x25 VGA text
console and starts the user-mode Shell automatically. Type help for commands.

The Shell workspace is /home/user. Successful file changes save before the
next prompt. If saving fails, use sync to retry.

See /boot/kernel.txt for system details and /boot/sources.txt for licensing.
